# ⚔️ World of Warcraft — Memory Game

A browser-based **Memory Card Game** inspired by the legendary **World of Warcraft** universe.

The goal of the game is simple: find all matching pairs of Warcraft characters using as few moves as possible.

---

## 🎮 About the Game

**World of Warcraft — Memory Game** is a classic memory matching game featuring iconic characters from the Warcraft universe.

The player needs to flip two cards and find matching characters.

When all pairs are found, the game is completed and the player's result is recorded in the leaderboard.

---

## ✨ Features

- 🃏 Memory card matching gameplay
- ⚔️ World of Warcraft themed characters
- 🔀 Random card shuffling
- 📊 Move counter
- 🏆 Completed pairs counter
- 🎉 Win screen
- 🔄 New Game button
- 🏅 Local leaderboard
- 💾 Leaderboard saved in `localStorage`
- 🎨 Alliance and Horde-themed designs
- 💾 Selected theme saved in `localStorage`
- 👤 Warcraft character information
- 🖼️ Character images
- ⚡ Built with Vite

---

## 🕹️ How to Play

1. Click on a card to reveal the character.
2. Click on another card.
3. If the characters match, the pair remains open.
4. If they don't match, the cards are hidden again.
5. Continue until all pairs are found.
6. Try to complete the game using as few moves as possible.
7. Your result is saved to the local leaderboard.

## ⚙️ Installation

Make sure you have Node.js installed on your computer.

Clone the repository:

```
git clone <your-repository-url>
```

Navigate to the project directory:

```
cd <project-folder>
```

Install dependencies:

```
npm install
```

---

## 🚀 Run Locally

Start the Vite development server:

```
npm run dev
```

Vite will start the local development server.

You should see something similar to:

```
Local: http://localhost:5173/
```

Open the displayed address in your browser.

---

## 📦 Build for Production

To create a production build:

```
npm run build
```

The generated files will be placed in:

```
dist/
```

## 👀 Preview Production Build

You can also preview the production build locally:
